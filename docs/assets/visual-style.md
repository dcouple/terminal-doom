# dcouple README visual language

Use a shared pixel-art world with a distinct setting for each product. The family
reference is the [Agent Farm banner](https://github.com/dcouple/agent-farm/blob/19f1fba8ef12050eef39c1b44e725c697b57b87b/docs/assets/agent-farm-banner.png).

## Shared rules

- Crisp coherent pixels, readable silhouettes, and isometric miniature scenes.
- Charcoal midnight backgrounds, warm cream lettering, and soft lantern light.
- Cream robots with dark faceplates and green eyes; clothes and props reflect their role.
- Restrained foliage, wood, stone, and floating islands connect the settings.
- Wide 3:1 banners: title left, scene right. Supporting images are roughly 2:1.
- Use each project's own setting, props, and accent colors. Avoid repeating the same farm under a new title.
- Keep technical labels and arrows accurate. Preserve real screenshots, demos, commands, and detailed diagrams.
- Do not depict planned features as shipped, implicit sharing as public, or required human approval as automatic.
- Keep alt text and text equivalents for information-bearing diagrams.

## This repository

A cozy retro gaming nook on a tiny rocky island, a cream robot gamer at an oversized terminal arcade cabinet showing a simple abstract red sci-fi corridor; lava-orange and muted red accents, warm amber controls and steel-grey terminal casing. playful classic first-person-game energy without gore, violence, weapon detail or copying a game screenshot. keep this an illustration of gaming inside a terminal. use familiar family robot rather than branded game characters

Local reference: [terminal-doom-banner.png](terminal-doom-banner.png).

Supply that banner as an image reference for future generation. Match its pixel
treatment, characters, lighting, and palette while adapting the scene to the
section. Save prompts and final assets in `docs/assets/`; inspect labels and
readability at README display width before embedding. Use new filenames for
experiments rather than overwriting chosen art.
